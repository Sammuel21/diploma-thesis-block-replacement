# Legacy Inputs

This directory preserves pre-wiki notes exactly as migration inputs.

- `researcher-notes/` contains researcher-authored drafts and topic maps.
- `source-lists/` contains source leads collected before the registry existed.

Do not edit these files to make them look canonical. During ingestion, create
new wiki pages with explicit provenance and retain links back to the original
legacy file. LLM-generated or mixed-authorship legacy material outside this
directory is registered separately in `raw/collections.yml`.
