# Historical MVP Notes

These files are preserved as unmodified design notes from the prototype phase.
They can provide migration input for the LLM wiki, but they are not canonical
methodology and should not be cited as external evidence.

- `data-flow.txt` sketches the early data flow.
- `modularity-separation-draft.md` records preliminary modularity concerns.
- `screening-draft.md` records the initial screening decomposition.

When a note is ingested, its claims must be separated into source-derived
material, researcher ideas, LLM synthesis, and empirical findings.
