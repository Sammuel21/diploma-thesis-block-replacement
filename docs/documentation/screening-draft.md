# Screening draft

## Block screening

### BI Score

BI ≈ 0
  X and Y point in almost the same direction
  block behaves directionally close to identity

BI ≈ 1
  X and Y are roughly orthogonal on average
  block strongly changes representation direction

BI > 1
  X and Y are on average more than orthogonal / partially opposite
  block strongly redirects representation
