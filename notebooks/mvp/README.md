# MVP Notebooks

These notebooks belong to the frozen prototype documented in
`docs/prototype/mvp/`. They remain at their original paths so their historical
outputs are preserved. Their helper modules (`scripts/`) and configuration
(`configs/`) live in this folder. The notebooks import them unchanged, which
works when the kernel starts here, the VS Code and Jupyter default.

Future maintained experiments should use the architecture established during
the codebase consolidation phase rather than extending these notebooks in
place.
